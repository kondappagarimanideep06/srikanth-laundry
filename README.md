# Sreekanth Laundry Shop

Professional Laundry, Dry Cleaning, and Steam Ironing Services website.

## Features
- **Modern Responsive Design**: Optimized for mobile, tablet, and desktop screens with glassmorphism and clean typography.
- **Service Showcase**: Wash & Fold, Eco Dry Cleaning, Steam Press Ironing, and Doorstep Pickup & Delivery.
- **Interactive Price Calculator**: Live weight & piece slider with real-time cost estimation in ₹.
- **Instant WhatsApp Booking**: Auto-formats order details and opens WhatsApp in one click.
- **Pickup Scheduling Form**: Custom date validation, preferred time slot selector, and instant confirmation receipt modal.
- **Customer Testimonials & FAQ**: Collapsible FAQ accordion and verified review cards.
- **Persistent Floating WhatsApp Button**: Direct customer inquiry access from anywhere on the page.

## Technologies Used
- HTML5 (Semantic Structure)
- Vanilla CSS3 (Custom Properties, Flexbox, Grid, Keyframe Animations)
- Vanilla JavaScript (Real-time Calculator, Modal System, WhatsApp API integration)
- Google Fonts (Outfit & Plus Jakarta Sans)

## Setup & Running Locally
1. Clone this repository:
   `ash
   git clone https://github.com/kondappagarimanideep06/srikanth-laundry.git
   `
2. Navigate into the directory:
   `ash
   cd srikanth-laundry
   `
3. Open index.html in any browser, or run a local server:
   `ash
   python -m http.server 8080
   `
4. Visit http://localhost:8080/ in your browser.
